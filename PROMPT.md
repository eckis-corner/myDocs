# Prompt: „myDocs“ – Dokumentenmanagement für den privaten Haushalt

## Ursprüngliche Idee (27.11.2026)

Es soll ein DMS-Tool werden. Aber anders als alle anderen soll es speziell für private Nutzer sein. D. h. Versicherungen, Banken, Abos etc. sind eigenständige Objekte. Mit einer Wiedervorlage soll eine Prüfung einzelner Objekte erzwungen werden. Durch einen Status soll eine Bearbeitung von Objekten gesteuert werden. Office-Dokumente (Word, Excel, PowerPoint – Microsoft oder LibreOffice oder andere) sollen so gespeichert werden können, dass diese immer wieder aktualisiert werden.

Die App soll als Blazor-Web unter .NET 10 auf meiner Synology laufen. Außerdem plane ich Clients für Windows, macOS und Linux.

Das Design soll wie myLife aussehen.

Zudem soll es eine Ergänzung zu myLife werden, bzw. beide Apps sollen zusammenarbeiten.
